# Talha Jubayer — Modern Portfolio

A responsive one-page portfolio built with plain HTML, CSS, and JavaScript.

## Structure

- `index.html` — page content
- `style.css` — design and responsive layout
- `script.js` — theme toggle, mobile menu, reveal animation
- `assets/profile.webp` — profile image
- `assets/favicon.svg` — favicon
- `CNAME` — custom domain configuration for GitHub Pages

## Local preview

Open `index.html`, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages

Upload all files to the root of a GitHub repository, enable Pages from the `main` branch, and set the custom domain to `itstalha.xyz`.
